# Office assets

Downloaded from [Poly Haven](https://polyhaven.com) (CC0, public domain), then compressed
(models: meshopt + webp textures at 512 px; textures re-encoded as jpg).

- `env/photo_studio_london_hall_1k.hdr`: daylight lighting
- `tex/laminate_floor_02_*`: the wood floor
- `tex/white_plaster_02_*`: the walls
- `models/potted_plant_02.glb`, `models/potted_plant_04.glb`: plants
- `models/ArmChair_01.glb`, `models/coffee_table_round_01.glb`: the lounge

Everything else in the office is modelled in code (`src/office/three`).
